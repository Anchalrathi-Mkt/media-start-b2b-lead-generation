# Media-Start | B2B Lead Generation & KPI Dashboard

## Project Overview
An Excel-based B2B prospecting and sales performance tracking project designed to organize leads, monitor sales opportunities, and support data-driven decision-making.

## Key Features
- B2B lead database and prospect tracking
- Lead source and opportunity type filters
- Lead status monitoring
- Follow-up and next-action tracking
- KPI dashboard for sales performance analysis

## Tools Used
Microsoft Excel, Data Validation, KPI Reporting, Sales Analytics
